# Peptide Library

> Peptide Library is an independent platform for researching peptides, comparing vendors and pricing, calculating concentrations, and tracking research. It does not sell peptides. Content is for research and educational use only and is not medical advice.

## Core Resources

* Home: https://peptidelibrary.app/
* Peptide library (200+ profiles: sequence, molecular data, mechanism, cited studies, regulatory status, FAQ): https://peptidelibrary.app/library
* Peptide stacks (46 peptide combinations by research goal, each with components, proposed rationale, an evidence grade and stated limitations; covers the Wolverine, GLOW, KLOW and CJC-1295 + Ipamorelin combinations): https://peptidelibrary.app/peptide-stacks
* Peptide dosage chart (studied dose, route, frequency and half-life by evidence level; states plainly where no human dosage is established): https://peptidelibrary.app/dosage-chart
* Vendor comparison: https://peptidelibrary.app/shop
* Calculator: https://peptidelibrary.app/calculator
* Peptide-specific calculators (vial presets, reconstitution chart, cited label/trial doses in syringe units): https://peptidelibrary.app/calculator/retatrutide, https://peptidelibrary.app/calculator/tirzepatide, https://peptidelibrary.app/calculator/semaglutide, https://peptidelibrary.app/calculator/cagrilintide, https://peptidelibrary.app/calculator/tesamorelin, https://peptidelibrary.app/calculator/bpc-157, https://peptidelibrary.app/calculator/bpc-157-tb-500, https://peptidelibrary.app/calculator/cjc-1295-ipamorelin

## Developer API

* Peptide Library REST API (v1, JSON, OpenAPI 3.1): research profiles, studies, regulatory status, categories and search without a key; vendor directory, products and prices with a free key. No dosing. Docs: https://peptidelibrary.app/developers/docs
* OpenAPI document: https://peptidelibrary.app/api/v1/openapi.json
* Developer portal (keys, SDKs, examples, terms): https://peptidelibrary.app/developers

## AI assistants (MCP server)

* MCP server for Claude, ChatGPT, Cursor and other MCP clients (Streamable HTTP, no authentication, read-only; research profiles, comparisons, educational content search and unit math; no dosing, vendors or prices): https://peptidelibrary.app/mcp
* MCP server documentation and setup: https://peptidelibrary.app/developers/mcp
